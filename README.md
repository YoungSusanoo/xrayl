# xrayl

Telegram-бот для изучения английского языка с личным словарём.
Получает определения из FreeDictionaryAPI.com, сохраняет выбранные значения
и синонимы в PostgreSQL. К значению можно добавить источник и контекст свободным текстом,
при желании включив в него главу, страницу или таймкод.

Основные команды: `/addword`, `/words`, `/addsource`, `/sources`.
Подробные сценарии — в [руководстве по командам](docs/commands.md).

## Быстрый запуск

Нужны Go версии из [go.mod](go.mod), Docker Compose и токен Telegram-бота.

```sh
cp .env.example .env
```

Укажите `BOT_TOKEN`, замените пример пароля в `POSTGRES_PASSWORD` и
`DATABASE_URL`. Остальные настройки описаны в [руководстве запуска](docs/setup.md).

```sh
docker compose up -d --wait
go run ./cmd/migrate up
go run .
```

Миграции применяются отдельной командой перед запуском бота.
PostgreSQL доступна на `127.0.0.1:5432` по умолчанию; данные сохраняются
в Docker volume. Отменённый ввод контекста не удаляет уже сохранённое значение.
