# Команды и сценарии

[README](../README.md) · [Запуск](setup.md) · [Архитектура](architecture.md)

Словарь и источники принадлежат Telegram-пользователю. Сессия диалога
определяется парой `(chatID, userID)`. Данные одного пользователя доступны
ему из разных чатов; переписка в групповом чате видна участникам этого чата.

## Команды

| Команда | Действие |
| --- | --- |
| `/addsource` | Создать источник по названию |
| `/sources` | Посмотреть личные источники |
| `/addword` | Найти слово, сохранить значение и по желанию добавить контекст |
| `/words` | Посмотреть сохранённые слова, значения, синонимы и контексты |
| `/next`, `/prev` | Переключить страницу списка |
| `/cancel` | Завершить текущий диалог; уже сохранённые данные остаются |
| `/skip` | Закончить добавление без контекста |
| `/retry` | Повторно загрузить список источников на этапе их выбора в `/addword` |

Четыре основные команды запускают новый диалог вместо текущего. `/next`,
`/prev`, `/skip`, `/retry` и `/cancel` обрабатываются внутри активного flow,
а не как самостоятельные сценарии. Без активного диалога обычное сообщение
не получает ответа. `/back`, редактирование и удаление через бота пока не
реализованы.

## Источники

Источник — название книги, статьи, фильма или другого места, где встретилось
слово. Создайте его заранее:

```text
Ты: /addsource
Бот: Введи название источника или /cancel.
Ты: Dune
Бот: Источник добавлен: Dune
```

Пробелы по краям названия удаляются. Пустой ввод и команды вместо названия
не принимаются. При повторе без учёта регистра возвращается существующий
источник с первоначальным написанием. `/cancel` завершает создание.
При ошибке БД можно повторить название.

`/sources` показывает источники по алфавиту без учёта регистра, по 20 на
странице. `/next` и `/prev` переключают страницы, `/cancel` завершает просмотр.
Номера в этом списке справочные: команда не открывает источник по номеру.
Пустой список сопровождается подсказкой `/addsource` и завершает диалог.

## Добавление слова и контекста

1. Отправьте `/addword`, затем английское слово.
2. Выберите номер определения из ответа словаря. Варианты содержат часть речи;
   нумерация общая для всего ответа, даже если список разделён на сообщения.
3. Выбранное значение немедленно сохраняется в PostgreSQL. При повторе
   используется прежний идентификатор, синонимы значения обновляются.
4. Если есть источники, выберите один номером. Список имеет страницы по 20
   источников и поддерживает `/next` и `/prev`.
5. Пришлите контекст одним сообщением. Можно самостоятельно включить в него
   цитату, комментарий, главу, страницу, ссылку или таймкод в любом формате.
   Непустой текст сразу сохраняется, после чего диалог завершается.
   Отдельного вопроса о месте нет; содержимое контекста не разбирается.

Если источников нет, сценарий заканчивается после сохранения значения с
подсказкой `/addsource`. Создание источника внутри `/addword` не предусмотрено.
Запуск `/addsource` заменит текущий диалог, автоматически назад он не вернётся.

Чтобы добавить контекст после создания источника или ещё один контекст к
тому же значению, снова пройдите `/addword` и выберите это значение.
Слово и значение не дублируются. Каждый успешный вызов сохранения контекста
создаёт новую запись, в том числе при совпадении текста контекста.

### Пропуск и отмена

| Этап | `/skip` | `/cancel` |
| --- | --- | --- |
| Ввод слова или выбор значения | Не предусмотрен | Завершает добавление до сохранения |
| Выбор источника | Завершает без контекста | Завершает без контекста |
| Ввод контекста | Завершает без контекста | Завершает без контекста |

После выбора значения отмена не удаляет его: бот сообщает, что значение
осталось в словаре. После успешного сохранения контекста диалог завершён;
последующий `/cancel` не удаляет его. Пустой ввод контекста вызывает подсказку. Текстовые поля диалогов не принимают ввод,
начинающийся с `/`, кроме поддерживаемых команд.

### Ошибки и повтор

- Ошибка словаря оставляет ввод слова активным. Для отсутствующего слова,
  ограничения частоты запросов и недоступности сервиса предусмотрены разные
  сообщения.
- Ошибка сохранения значения позволяет повторить номер без нового запроса
  к словарю.
- Ошибка загрузки источников не сохраняет значение заново. Если список ещё
  не загружен, `/retry` загружает первую страницу; если уже загружен — текущую
  сохранённую страницу. После ошибки перехода `/next` или `/prev` можно
  повторить именно этот переход. Старые номера остаются доступны.
- При ошибке сохранения контекста выбранный источник остаётся в сессии.
  Пришлите текст контекста ещё раз; `/skip` или `/cancel` завершат добавление
  без контекста, сохранив значение.
- Ошибка отправки подтверждения не откатывает успешную запись в БД.

## Просмотр слов

`/words` выводит слова по алфавиту без учёта регистра. Каждое слово
отображается один раз, независимо от количества сохранённых значений.
Исходное написание сохраняется.

На странице до 20 слов; номера на каждой странице начинаются с 1.
Отправьте номер, чтобы увидеть все сохранённые определения и их синонимы.
Контексты сгруппированы под соответствующими значениями: источник и полный
текст пользователя. Данные читаются из PostgreSQL без обращения к словарю.

После карточки можно отправить другой номер с той же страницы или продолжить
просмотр через `/next` и `/prev`. `/words` заново открывает первую страницу;
`/cancel` завершает просмотр. Пустой словарь сопровождается подсказкой
`/addword` и завершает диалог.

При ошибке загрузки значений или контекстов можно повторить номер. Если
контексты загрузить не удалось, неполная карточка не отправляется.
Страница хранит соответствие номеров идентификаторам слов; изменения БД
отражаются при следующей загрузке страницы или повторном `/words`.

## Пример полного сценария

Диалог сокращён; определения и их номера зависят от текущего ответа API.

```text
Ты: /addsource
Бот: Введи название источника или /cancel.
Ты: Dune
Бот: Источник добавлен: Dune

Ты: /addword
Бот: Введи английское слово или /cancel.
Ты: book
Бот: [Нумерованные определения]
Ты: 1
Бот: [Карточка сохранённого значения]
Бот: Твои источники · Страница 1
     1. Dune
     Пришли номер источника.
Ты: 1
Бот: Пришли контекст одним сообщением.
     При желании добавь главу, страницу или таймкод.
Ты: He opened the book.
     Chapter 2, page 12
Бот: Контекст сохранён.

Ты: /words
Бот: Твои слова · Страница 1
     1. book
Ты: 1
Бот: [Сохранённое определение и синонимы]
     Источник: Dune
     He opened the book.
     Chapter 2, page 12
```

Текст в примере вымышлен и иллюстрирует ввод пользователя.
Связь контекста с источником, наличие слова и указания места автоматически
не проверяются.

Длинные списки и карточки разделяются на сообщения до 3000 единиц UTF-16
без обрезания текста. Незавершённые диалоги теряются при перезапуске.
